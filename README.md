# 从夯到拉排行





预览图   

![preview](./static/preview.png)


使用方法：   
克隆项目或下载压缩包到本地后解压；   
双击index.html文件，在浏览器打开网页；   
将图片放到【imgs】目录，在index.html文件中的availableImages中添加文件名；   
在网页中将图片拖拽到对应容器，点击容器的图片可以移除；
